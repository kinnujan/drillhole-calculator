# QUICKLOG PWA - Project Plan

## Core Architecture

### Data Model
- LogEntry structure based on configuration.csv
  - Required fields: holeid, from, to
  - Dynamic fields from configuration (domains, booleans, numbers, text)
- Smart interval handling
  - Auto-population of from/to fields based on adjacent intervals
  - Validation of interval continuity
  - No gaps allowed between intervals

### Configuration Management
- Configuration.csv as source of truth
  - Field definitions
  - Domain lists
  - Validation rules
- Sync with Dropbox
  - Automatic sync with quicklog.csv
  - Version tracking for conflict resolution

### Storage & Sync
- IndexedDB for local storage
- Dropbox integration
  - File versioning for conflict resolution
  - UUID-based entry identification
  - Background sync with copy preservation
- Offline capability
  - Local-first architecture
  - Automatic background sync
  - Conflict resolution with version preservation
